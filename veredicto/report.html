FAQ

Frequently asked questions

How was the experiment run?

Twenty modules were seeded with a real, behaviour-changing bug each. Fast AI agents were then asked to write thorough unit tests for every module, without being told a bug was present. The resulting suites were run against the buggy code.

What does "0% caught the bug" mean exactly?

It means no suite produced a failing test that exposed the seeded bug. All twenty went green against code that was known to be wrong.

Does this mean AI should not write tests?

No. It means a green suite written by the same agent that wrote the code is not evidence the code works. The tests still have value as regression scaffolding; they just cannot be the thing that verifies correctness.

Can I reproduce this myself?

Yes. The seeded modules and the scorers are in the public repository, so you can run the same experiment against your own model and compare.

What catches this in a real pull request?

A human reviewer, mutation testing, or a deterministic check like Veredicto that flags the specific patterns — over-mocking, tautological asserts, mocking the unit under test — before the pull request is merged.
