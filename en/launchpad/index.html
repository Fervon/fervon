Get started

Clone it inside your folder and run

It lives inside the folder it manages. Clone it, build the UI once and serve everything on one port.

$ git clone https://github.com/JoniMartin27/launchpad
$ cd launchpad
$ npm install
$ npm run build # builds the web UI
$ npm start # UI + API + WS at http://127.0.0.1:7777

Open http://127.0.0.1:7777. It scans the parent folder, seeds a config.json and shows your projects.

FAQ

Frequently asked questions

How does it avoid port clashes?

It reserves a dedicated port per project inside a dedicated range and passes it in at launch, instead of letting everything grab port 3000. That is how a dozen services can run at once.

Do I have to configure each repo by hand?

No. It scans the folder, recognises the project type and infers the start command. You only touch the config if you want to change something specific.

Is it for deploying to production?

No, and that is deliberate. It is a local development tool: it brings your working environment up on one screen. It does not open ports to the outside or manage servers.

How much does it cost?

Nothing. Free and open source, with no account and no sign-up.
