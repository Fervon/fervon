FAQ

Frequently asked questions

Which platforms does it post to automatically?

It posts via API to whichever channels have credentials connected —among them Bluesky, Mastodon and DEV.to—. For networks without an open API it generates the adapted text ready to paste.

Does it post the same text everywhere?

No, and that is the point. You write one canonical message and Pregón adapts it to each network format, length and conventions before posting.

Where are my credentials stored?

In your own installation. Pregón runs wherever you put it and there is no central third-party service holding them.

What does the traction tracking measure?

Real numbers pulled from public APIs: npm and PyPI downloads and GitHub stars, grouped per project, so you can see whether an announcement moved anything.
